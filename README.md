# project-orm-framework

This framework frees the application developer from writing SQL statements.





ORM Framework is a Java-based tool that analyzes database tables using JDBC *DatabaseMetaData* and generates java classes corresponding to database tables.

This tool is a part of my Web-Services framework.



###### 

###### **Why Is This Tool Useful?**

&#x20; 

Manually creating Java classes from database tables is repetitive and time-consuming. The project automates the process by analyzing database metadata and generating the required information. The extracted information is stored in data structures.

For example, if a database contains 100 tables, a developer would have to manually analyze each table, identify its columns, data types, primary keys, foreign keys and, other constraints, and then create the corresponding Java classes.
